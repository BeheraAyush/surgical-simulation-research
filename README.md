# Surgical Simulation Research

An early-stage research prototype exploring interactive medical imaging, 3D visualization, and tissue deformation simulation.

## Vision

The long-term goal is to explore patient-specific surgical simulation through interactive medical imaging, biomechanics, and visualization.

## Current milestones

- DICOM workflow exploration
- Multi-planar image viewing (Axial, Coronal, Sagittal)
- 3D visualization experiments
- Interactive tissue deformation prototype
- Force and stiffness simulation
- Live deformation metrics

## Status

This repository marks the public genesis of the project. Development is currently in hibernation before the next major phase.
